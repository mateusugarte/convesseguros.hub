# Mapa Estrategico

## Objetivo central

Fazer a Conves crescer com estrutura, sem perder identidade, controle ou qualidade de atendimento.

## Direcao geral

A empresa precisa combinar tres movimentos ao mesmo tempo:

- manter a operacao organizada
- usar o sistema para gerar previsibilidade
- transformar base e relacionamento em crescimento

## Metodos de alto nivel

### 1. Metodo para crescimento comercial

Usar o CRM, as campanhas e as jornadas para organizar a prospeccao, ativacao e conversao de oportunidades.

Esse metodo sera usado para:
- aumentar previsibilidade de receita
- aproveitar melhor a base existente
- estruturar a expansao comercial com mais controle

### 2. Metodo para fortalecimento da base

Usar o sistema operacional e a documentacao para criar uma base confiavel, rastreavel e util para novas decisoes.

Esse metodo sera usado para:
- reduzir perda de informacao
- melhorar a qualidade da operacao
- gerar inteligencia a partir do historico

### 3. Metodo para posicionamento de marca

Usar comunicacao, cultura e experiencia pratica para consolidar a imagem da Conves como uma empresa que resolve, acompanha e organiza.

Esse metodo sera usado para:
- fortalecer confianca
- criar coerencia entre discurso e pratica
- sustentar a percepcao de valor da marca

### 4. Metodo para retenção e relacionamento

Usar renovacoes, atendimento e acompanhamento para manter proximidade com a base e prolongar o ciclo de valor do cliente.

Esse metodo sera usado para:
- preservar carteira
- ampliar relacionamento
- gerar novas oportunidades dentro da base existente

## Objetivos estrategicos

- crescer com previsibilidade
- usar tecnologia como alavanca de organizacao
- transformar base em ativo estrategico
- manter a cultura da Conves como diferencial
- conectar operacao, comercial e relacionamento

## Resultado esperado

A Conves passa a operar com mais clareza sobre:

- onde esta crescendo
- o que sustenta esse crescimento
- quais metodos funcionam melhor
- quais frentes exigem prioridade
