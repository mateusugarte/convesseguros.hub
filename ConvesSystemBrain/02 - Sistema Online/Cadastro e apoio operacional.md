# Cadastro e apoio operacional

## Objetivo do setor

Manter a base limpa, organizada e util, sustentando a qualidade das informacoes que circulam no sistema.

## Fluxo simples

- a informacao chega
- o usuario confere
- organiza os dados
- deixa o registro pronto para uso pelos demais setores

- menor indice de erro

- melhor fluidez entre setores

- este setor garante que o sistema continue funcional e consistente
