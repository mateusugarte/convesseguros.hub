# Fluxo de Handoff

## Objetivo

Garantir que a mesma informacao seja aproveitada por Claude e ChatGPT sem conflito de versao.

## Fluxo

1. O conteudo nasce no Obsidian.
2. O conteudo e aprovado.
3. Claude recebe a estrutura para criar a leitura visual.
4. ChatGPT recebe a mesma base para criar os documentos explicativos.
5. As respostas voltam para o Obsidian.
6. O Obsidian passa a ser a versao consolidada.

## Regra

Nada entra como oficial antes de ser consolidado no cérebro.

## O que vai para cada IA

### Claude

- mapa geral
- estrutura de páginas
- conexoes
- visual da apresentação

### ChatGPT

- objetivos
- contexto
- justificativas
- descrições mais extensas
- documentos de apoio
